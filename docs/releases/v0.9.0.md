# Tomlook v0.9.0

This release adds native Windows reminders before meetings. These are
changes since [v0.8.0](https://github.com/tkubica12/ai-outlook/releases/tag/v0.8.0).
If you run v0.8.0, this update installs itself after a verified download when
you choose **Restart now** in Settings → Updates or exit Tomlook.

## Meeting reminders

Shortly before a meeting starts (5 minutes by default), Tomlook shows a
Windows notification, also while it is hidden in the tray:

- **In 5 min · 09:15–10:45** (**Za 5 min** in Czech), the original meeting
  title and location;
- up to three short points from the meeting's saved Insights: next steps,
  then talking points, then open questions. A reminder never starts AI;
- **Join** for a safe Teams link (Windows opens it directly), **Open** for
  the meeting details, and Windows Snooze with 1–15 minutes.

Reminders cover timed meetings you organize or have accepted. Tentative
meetings are optional (off by default). Unanswered, declined, cancelled, free
and followed meetings are skipped. Each occurrence is reminded once, including
across restarts; a moved meeting replaces its earlier reminder. After sleep,
a missed reminder still appears if the meeting has not started more than two
minutes ago.

**Settings → Notifications** (**Nastavení → Oznámení**) controls reminders,
the lead time (1, 2, 5, 10 or 15 minutes), tentative meetings and offers
**Send test notification** with fictional content. Tomlook registers itself
for the current user as `Tomlook.Calendar` under
`HKCU\Software\Classes\AppUserModelId`, so Windows Settings → System →
Notifications can turn its notifications off or change how they appear.

## Download and upgrade

v0.8.0 installs this release automatically after verification. Otherwise
download `Tomlook-v0.9.0-win-x64.zip`, fully exit Tomlook (including its tray
instance) and replace `Tomlook.exe`. Keep the existing `%LOCALAPPDATA%\Tomlook`
profile. Runtime and connection requirements are unchanged; see
[native setup](https://github.com/tkubica12/ai-outlook/blob/v0.9.0/native/README.md).

## Verification scope

Offline tests cover eligibility, timing with late and skipped reminders,
once-only delivery across restarts, Insights point selection in both languages
and escaped notification XML. A test notification was delivered to the Windows
notification center with the expected content and actions, and the Open
activation restored the window. A pop-up banner could not be observed because
the test session's screen was locked. A real scheduled reminder has not yet
fired live.
