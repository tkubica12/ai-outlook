# Tomlook v0.7.0

This release lets the assistant propose concrete edits instead of only
describing them, and prepares the codebase and release process for the next
features. These are changes since
[v0.6.1](https://github.com/tkubica12/ai-outlook/releases/tag/v0.6.1).

## AI-proposed edits with explicit approval

Quick, Thorough and Auto conversations can now stage a typed **pending
proposal** for:

- replacing selected sections of saved bilingual Insights or meeting notes
  (summary, preparation, talking points, open questions, risks, gaps);
- setting or clearing ordinary categories while preserving Follow;
- adding one travel block before or after an accepted timed meeting;
- editing the title or description of an event you organize.

**Review changes** in the answer opens the exact proposal in Messages (also
reachable from the bell) with its meeting, reason and before/after preview.
Nothing changes until you choose **Approve change**. Saying "approve" in chat,
opening the preview or continuing the conversation never executes it.
Pending proposals and consumed approvals survive restart.

Local document approvals need no WorkIQ connection and keep untouched
sections and original evidence. Approved sections survive later automatic
preparation. Calendar proposals reuse the single-use, read-back-verified
writer; uncertain outcomes are never replayed automatically. Online meeting
descriptions can be extended without replacing the Teams join information.
See [AI-proposed edits](https://github.com/tkubica12/ai-outlook/blob/v0.7.0/native/README.md#ai-proposed-edits)
for limits and safeguards.

## Internal changes

- The native UI module is split from one 10,400-line file into focused
  modules (calendar, meeting details, Ask, recommendations, connections,
  settings, event editor, command palette). Behavior is unchanged.
- `scripts\package-release.ps1` builds, stages and publishes releases.
  Third-party notices are regenerated from the locked dependency graph and now
  also include previously omitted Unlicense and font license texts.

## Download and upgrade

Download `Tomlook-v0.7.0-win-x64.zip`, extract it, and run `Tomlook.exe`.
This is a portable, unsigned Windows 10/11 x64 application, not an installer.
Its Windows file/product version is `0.7.0`. The archive contains the
executable, project license and third-party/font notices. `SHA256SUMS.txt`
supplies checksums for the executable and ZIP.

Fully exit Tomlook, including its tray instance, before replacing the
executable. Keep the existing `%LOCALAPPDATA%\Tomlook` profile. Runtime and
connection requirements are unchanged; see
[native setup](https://github.com/tkubica12/ai-outlook/blob/v0.7.0/native/README.md).

## Verification scope

All offline unit and integration tests and Clippy with warnings denied pass.
The offline demo was rendered after the module split. No live calendar writes
were performed for this release.
