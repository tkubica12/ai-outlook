# Tomlook v0.18.1

This release adds bulk invitation triage and makes paired travel blocks
available for accepted invitations as well as meetings you organize.
These are changes since
[v0.18.0](https://github.com/tkubica12/ai-outlook/releases/tag/v0.18.0).

## Handle several invitations together

In **Invitations**, use checkboxes, Ctrl+click or Shift+click to select multiple
rows in **Important**, **Other** or **Snoozed**. **Select page** marks the current
page; selections persist across pages in the same tab. Changing tabs or
returning to Calendar clears the selection.

Right-click a selected row, or use **Selected invitation actions**, to:

- **Decline without sending**: decline every listed invitation without
  notifying its organizer.
- **Follow selected invitations**: preserve the invitation response and other
  categories, add Follow and mark each listed occurrence as free.

Both actions show the exact list and require one confirmation. Right-clicking
an unselected row targets only that row. Recurring invitations affect only the
displayed occurrence, never the whole series.

Writes run sequentially through the existing verified calendar-write path,
with an individual approval and outcome for each occurrence in **Messages**.
Account changes, changed invitations and duplicate approvals are rejected;
failed or uncertain changes are not retried automatically. Filtered invitation
metadata never establishes full-calendar coverage.

## Add travel blocks from the meeting menu

Right-click your own timed meeting or an accepted invitation and choose
**Add travel blocks** (**Přidat přejezdy** in the Czech interface). A simple
dialog offers one duration slider, from 15 to 180 minutes in 15-minute steps,
defaulting to 30 minutes before and after the meeting.

Confirmation creates only two personal busy blocks. It does not modify or
recreate the meeting, copy its attendees or notify anyone. Private meetings
keep their travel blocks private. The existing account, parent-snapshot,
calendar-coverage and conflict checks remain in place.

## Download and upgrade

v0.8.0 and later can install this release after signed-update verification
when you choose **Restart now** in Settings -> Updates or exit Tomlook.
Otherwise download `Tomlook-v0.18.1-win-x64.zip`, fully exit Tomlook including
its tray instance and replace `Tomlook.exe`. Keep the existing
`%LOCALAPPDATA%\Tomlook` profile.

The release includes checksums, third-party notices and a signed update
manifest.

## Verification scope

Offline verification covers the native UI suite, invitation integration,
selection and context-menu behavior in English and Czech, exact bulk approvals,
serialized writes, individual verified and uncertain outcomes, queue failures,
stale selections, account isolation and paired travel for both organizers and
attendees. No live RSVP or travel-block write was performed for verification.

The pre-existing
`invitation_previews_never_enter_preparation_or_meeting_questions` failure
documented in v0.18.0 remains outside these changes: the unchanged preparation
prompt exceeds its existing 8,000-byte question limit. This release does not
claim a full-library-suite pass.
