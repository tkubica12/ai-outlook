# Tomlook v0.19.2

This release fixes the customer confirmation dialog when MSX finds many
matching customers. These are changes since
[v0.19.1](https://github.com/tkubica12/ai-outlook/releases/tag/v0.19.1).

## Customer confirmation fits the screen

When MSX returned several candidates with their evidence, **Confirm customer**
grew taller than the screen and **Confirm** and **Cancel** were out of reach.

The dialog body now scrolls within the screen height. **Confirm** and
**Cancel** always stay visible below it. The MSX search and matching are
unchanged.

## Download and upgrade

v0.8.0 and later can install this release after signed-update verification
when you choose **Restart now** in Settings -> Updates or exit Tomlook.
Otherwise download `Tomlook-v0.19.2-win-x64.zip`, fully exit Tomlook including
its tray instance and replace `Tomlook.exe`. Keep the existing
`%LOCALAPPDATA%\Tomlook` profile.

The release includes checksums, third-party notices and a signed update
manifest.

## Verification scope

A new app test shows six MSX candidates and 40 territory customers on a
700-pixel-high screen. It checks that **Confirm** stays on screen and saves the
chosen MSX customer. The test fails without this fix.

App tests and Clippy passed. The two unrelated failing tests listed in
[v0.19.1](https://github.com/tkubica12/ai-outlook/releases/tag/v0.19.1) still
fail.
