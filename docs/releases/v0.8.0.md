# Tomlook v0.8.0

This release adds signed automatic updates. These are changes since
[v0.7.0](https://github.com/tkubica12/ai-outlook/releases/tag/v0.7.0).
**Install v0.8.0 manually once**; later releases arrive automatically.

## Automatic, verified updates

About a minute after start, and then at most once a day while Tomlook runs
(also hidden in the tray), it asks GitHub Releases whether a newer version
exists. That is one unauthenticated request to `api.github.com`; no calendar
or account data is sent.

A newer release is accepted only if:

- its `tomlook-update.json` manifest carries a valid Ed25519 signature from
  a key embedded in Tomlook (checked before the manifest is even parsed);
- the manifest names the same release, a strictly newer stable version and
  the expected archive;
- the downloaded ZIP matches the signed size and SHA-256, contains only
  `Tomlook.exe`, `LICENSE` and `THIRD_PARTY_NOTICES.txt`, and the extracted
  executable matches its signed SHA-256.

The verified update is staged next to `Tomlook.exe`. Choose **Restart now**
in **Settings → Updates** (**Nastavení → Aktualizace**), or simply exit
Tomlook, and the new executable replaces the old one. A failed replacement is
rolled back. A small **Update X.Y.Z ready** link appears in the status bar only
when a verified update is waiting.

Automatic checks can be turned off in Settings → Updates; **Check now** stays
available. Updates are disabled in the offline demo, stress and measurement
modes and in development builds. If the folder is not writable, Tomlook
offers only the release page.

## Download and upgrade

Download `Tomlook-v0.8.0-win-x64.zip`, extract it, and run `Tomlook.exe`.
Fully exit Tomlook, including its tray instance, before replacing the
executable. Keep the existing `%LOCALAPPDATA%\Tomlook` profile.
`SHA256SUMS.txt` lists checksums for the executable and ZIP;
`tomlook-update.json` and its `.sig` are the signed update manifest.

The executable itself is still not Authenticode-signed, so Windows SmartScreen
may warn on first manual start. Runtime and connection requirements are
unchanged; see
[native setup](https://github.com/tkubica12/ai-outlook/blob/v0.8.0/native/README.md).

## Verification scope

Offline tests cover signature acceptance/rejection, manifest validation,
version comparison, archive extraction with traversal and hash-mismatch
rejection, install rollback and the relaunch handover between instances.
The release manifest was signed and verified against the real archive before
publishing. An end-to-end live update will first be possible with the next
release.
