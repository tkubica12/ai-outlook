# Tomlook v0.16.0

This release adds a setup checklist and a first-run welcome, so connecting
Tomlook no longer requires reading long setup documentation. These are changes
since [v0.15.0](https://github.com/tkubica12/ai-outlook/releases/tag/v0.15.0).
v0.8.0 and later install it automatically after verification when you choose
**Restart now** in Settings → Updates or exit Tomlook.

## Setup checklist

**Settings → Setup** (**Nastavení připojení**), also available from Commands,
shows what is connected, what is missing and what to do next:

| Step | Required | Shows |
|---|---|---|
| Microsoft 365 calendar (WorkIQ) | yes | sign-in and how many days are synchronized |
| GitHub Copilot | yes | isolated sign-in and the installed Copilot CLI runtime |
| Identity match | yes | whether automatic Insights can run, and the exact reason if not |
| Windows notifications | yes | whether Windows allows Tomlook notifications, with a test |
| Updates | yes | automatic checks and the last result |
| WebIQ, GitHub, Foundry, MSX | optional | connection state; Azure CLI presence where needed |
| Runtime prerequisites | info | Visual C++ runtime, Azure CLI, Copilot runtime |

The header summarizes progress ("4 of 5 required steps done") and **Next
step** opens the first incomplete required item. Each button opens the same
connection dialog or runs the same action as the status bar; nothing signs in
until you click.

A small **Setup x/5** indicator appears in the status bar while a required
step is incomplete. Right-click → **Don't show** hides it permanently.

## First-run welcome

A new profile without any saved connection opens a short **Welcome**
(**Vítejte**) window once, with language and theme choice and the required
steps. Existing profiles that already have a saved connection never see it.

## Download and upgrade

v0.8.0 and later update automatically. Otherwise download
`Tomlook-v0.16.0-win-x64.zip`, fully exit Tomlook (including its tray
instance) and replace `Tomlook.exe`. Keep the existing `%LOCALAPPDATA%\Tomlook`
profile.

## Verification scope

Offline tests cover the status of every item from connection states, the
summary, next-step selection, welcome rules for new and upgraded profiles and
the dismissible indicator. The checklist and welcome were checked visually in
the offline demo; connected states have not yet been observed with a live
profile.
