# Tomlook v0.10.0

This release adds feedback on AI output and uses it to suggest better prompts.
These are changes since
[v0.9.0](https://github.com/tkubica12/ai-outlook/releases/tag/v0.9.0).
v0.8.0 and later install it automatically after verification when you choose
**Restart now** in Settings → Updates or exit Tomlook.

## Rate Insights and meeting notes

Meeting Insights and post-meeting notes now have small **Helpful** /
**Not helpful** (**Užitečné** / **Neužitečné**) thumbs, for the whole document
in meeting details and for every section in the expanded view.

- Thumbs up saves immediately; clicking the same thumb again clears it.
- Thumbs down asks what was wrong: inaccurate, not relevant, missing something
  important, too long, too vague, wrong language or other, plus an optional
  comment of up to 500 characters.
- A rating belongs to the exact text you saw. Re-researched or translated text
  starts unrated, while older ratings still count in the summary.

Feedback is stored only in your local Tomlook profile and is never sent
anywhere automatically. New Insights and notes also remember which prompt
version produced them.

## From feedback to a better prompt

**Settings → AI prompts** summarizes the last 90 days for the
before-the-meeting and after-the-meeting prompts: helpful and not-helpful
counts, the most common reasons, the most criticized sections and the newest
comments with their meetings.

**Suggest prompt improvement** sends one tool-free request (Thorough profile,
counted against the daily AI limit) with the current editable prompt, the
aggregated feedback and up to 20 recent negative ratings with short excerpts.
The answer appears as a draft with its rationale and a before/after diff.
**Use draft** only copies it into the editor; nothing changes until you choose
**Save prompts**. Fixed safety, source and output rules are never editable.

## Download and upgrade

v0.8.0 and later update automatically. Otherwise download
`Tomlook-v0.10.0-win-x64.zip`, fully exit Tomlook (including its tray
instance) and replace `Tomlook.exe`. Keep the existing `%LOCALAPPDATA%\Tomlook`
profile; the new feedback table is added automatically.

## Verification scope

Offline tests cover storage and re-rating, clearing, revision binding, the
90-day summary, the bounded suggestion request and rejection of empty,
unchanged or oversized suggestions. The rating controls, reason panel and
settings summary were checked visually in the offline demo. A live prompt
suggestion has not yet been run against a signed-in Copilot account.
