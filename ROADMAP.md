# Roadmap

1. **Delegated authentication:** Entra authorization-code/OBO flow, encrypted token cache,
   refresh, consent handling, and per-user connector isolation.
2. **Real agent runtime:** structured streaming, cross-source MCP orchestration, isolated
   workspaces, and richer audit records.
3. **Business data:** governed CRM/Dataverse and Power BI/ACR adapters.
4. **Production operations:** durable job queue, managed storage, multi-user isolation,
   observability, retention controls, and Azure Container Apps deployment.
5. **Personalization:** richer preference controls and reviewed, reversible skill lifecycle.

Azure Container Apps Sandboxes are intentionally deferred during local product iteration.
